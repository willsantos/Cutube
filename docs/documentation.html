Documentação

Instalação, atualização e manutenção do Cutube — a CLI que baixa e corta vídeos do YouTube no terminal.

Instalação rápida

Cole a linha correspondente ao seu sistema no terminal. O script detecta a plataforma, instala o binário no PATH e mantém tudo atualizado.

Linux e macOS
$ curl -fsSL https://willsantos.github.io/Cutube/install.sh | bash
Windows (PowerShell)
PS> iwr -useb https://willsantos.github.io/Cutube/install.ps1 | iex
Fallback (Raw GitHub)
$ curl -fsSL https://raw.githubusercontent.com/willsantos/Cutube/main/scripts/install.sh | bash
PS> iwr -useb https://raw.githubusercontent.com/willsantos/Cutube/main/scripts/install.ps1 | iex

Instalação manual

Sem script: baixe o pacote da sua plataforma nas releases e coloque o executável no PATH.

  1. Acesse as releases.
  2. Baixe o pacote da sua plataforma.
  3. Extraia e mova o executável para uma pasta no PATH.
$ tar -xzf cutube-linux-amd64.tar.gz
$ sudo install -m 755 cutube /usr/local/bin/cutube

Dependências opcionais

Zero configuração é o padrão: se algo essencial faltar, o Cutube resolve sozinho no primeiro uso.

  • yt-dlp (ou youtube-dl). Para metadados e fluxos adicionais. Se não estiver instalado, o Cutube baixa sozinho no primeiro uso.
  • ffmpeg. Para processamento multimídia. No Windows, o Cutube baixa automaticamente o build estático oficial de BtbN/FFmpeg-Builds (~120 MB) em %LOCALAPPDATA%\Cutube. Em Linux e macOS, prefira o gerenciador de pacotes.

Instalando pelo gerenciador de pacotes

macOS / Ubuntu
$ # macOS
$ brew install ffmpeg yt-dlp
$ # Ubuntu/Debian
$ sudo apt install ffmpeg
$ python3 -m pip install -U yt-dlp
Windows (winget)
PS> winget install yt-dlp.yt-dlp Gyan.FFmpeg

Atualização

Automática (padrão)

A CLI verifica no máximo 1x por dia se existe versão nova (releases/latest no GitHub, timeout de 3s). Se houver e a sessão for interativa, ela pergunta:

Nova versao disponivel: v1.3.0 (atual: 1.2.1)
Deseja atualizar agora? [S/n]:
  • Enter ou s: baixa o binário da sua plataforma, substitui o executável e reinicia o comando pedido na versão nova (exit code propagado).
  • n: o comando executa normalmente na versão atual.
  • Sem rede, timeout ou erro de permissão: a CLI apenas avisa e continua na versão atual, sugerindo o comando manual.

Em scripts/CI (stdin redirecionado) a verificação é pulada silenciosamente; o comando explícito cutube update nesse contexto atualiza sem perguntar.

Forçada

$ cutube update # ignora o cache diario e verifica na hora

Desativando a verificação automática

No arquivo de configuração (cutube config show mostra o caminho):

{ "checkForUpdates": false }

Configs antigas sem esse campo ficam com o padrão true.

Manual

Re-execute o instalador da sua plataforma (sempre instala a latest release e sobrescreve o binário) ou baixe o asset direto nas releases.

Nota: no Windows, ao atualizar em execução o binário anterior fica como cutube.exe.old ao lado do novo e é removido na próxima inicialização.

Verificação

Confirme que tudo está no lugar.

$ cutube --version
$ cutube --help

Desinstalação

Remove o executável; as entradas de PATH permanecem se você quiser reinstalar depois.

Linux e macOS
$ sudo rm -f /usr/local/bin/cutube
$ rm -f ~/.local/bin/cutube
Windows
PS> Remove-Item cutube.exe

Remova cutube.exe da pasta de instalação e, se quiser, limpe a entrada de PATH correspondente.

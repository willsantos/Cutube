Baixe. Corte.
Direto do terminal.

Cutube é a CLI da Oroborus que baixa vídeos e áudio do YouTube e corta no tempo exato — direto do terminal, sem servidor e sem configuração.

Instalar agora Ver no GitHub
terminal
$ curl -fsSL https://willsantos.github.io/Cutube/install.sh | bash

Instale com um comando

Cole a linha correspondente ao seu sistema no terminal. O script detecta a plataforma, instala o binário no PATH e mantém tudo atualizado.

Linux e macOS
$ curl -fsSL https://willsantos.github.io/Cutube/install.sh | bash
Windows (PowerShell)
PS> iwr -useb https://willsantos.github.io/Cutube/install.ps1 | iex
Fallback (Raw GitHub)
$ curl -fsSL https://raw.githubusercontent.com/willsantos/Cutube/main/scripts/install.sh | bash
PS> iwr -useb https://raw.githubusercontent.com/willsantos/Cutube/main/scripts/install.ps1 | iex

O que vem incluído

Zero configuração é o padrão do Cutube: as dependências difíceis já resolvem sozinhas.

  • yt-dlp incluído. O downloader já vem no pacote e se atualiza sozinho — nenhuma instalação extra.
  • Corte por tempo nativo. Informe início e fim e receba só o trecho que interessa, em vídeo ou MP3.
  • FFmpeg: no Windows é baixado automaticamente no primeiro uso; em Linux e macOS, instale pelo gerenciador de pacotes (brew install ffmpeg ou sudo apt install ffmpeg).

Próximos passos

Instalou? Confirme e comece a usar.

  1. Confirme a instalação com cutube --version.
  2. Baixe um corte: cutube download <url> -s 00:01:00 -e 00:05:30.
  3. Veja a instalação manual e o troubleshooting na documentação completa ou pegue o binário direto nas releases.
